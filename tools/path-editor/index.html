Path editor

Top-down XZ map. Copy TypeScript into src/path/route.ts, or paste that same block below to reload a map.

Tool

Drag to move. First waypoint is Start; the path does not loop. Double-click a later waypoint to toggle a stop. Remove waypoint clicks a point to delete it. Right-drag pans. Wheel zooms.

Playback

0 = constant speed. 1 = longest ramp up from a stop and down into the next.

Inspector

Nothing selected.
